## 1. 安装与启动

### 方式一：当前源码版的 Windows 启动入口

双击项目根目录的 `启动软件.bat`。独立运行环境位于本项目的 `.venv` 文件夹；换电脑使用源码版时，请先安装 Python 3.9 或更高版本，建议使用 3.12 或 3.13，并重新创建环境。

首次准备环境需要联网安装核心依赖，后续直接使用项目内的环境。中文路径下的 Qt 插件查找已作兼容处理。启动失败时，请保留提示窗口，查看根目录 `启动日志.txt`；软件运行日志位于工作区 `logs/app.log`。环境目录变更不影响题目数据的位置。当前尚未提供经过验证的免安装 exe 或 Mac app。

### 方式二：从源码运行

```bash
pip install -r requirements.txt
python main.py
```

### 关于联网

文本分类和 Excel 归档在本地运行，不需要上传错题。首次安装依赖需要联网。印刷图片文字识别可通过项目内“安装图片识别.bat”准备，之后只使用本地模型。听力已验证本机 `faster-whisper==1.2.1` 的 `base` 模型转写流程，但结果仍需人工核对；复杂公式识别仍待 pix2tex。缺少识别组件或模型时，可手动录入题干和标注进行分类。

### 你的数据在哪

全部在 `~/.mistake_classifier/` 下：

```
~/.mistake_classifier/
├── data/          错题、分类体系、反馈记录
├── media/         你导入的图片和音频（程序会自动拷一份进来）
├── exports/       导出的 Excel 与归档文件夹
├── model/         分类学习增量与权重
├── backups/       手动备份及恢复前的自动备份（首次备份后出现）
└── logs/          运行日志（出问题时可以看这里）
```

点击主窗口顶部“备份与恢复”，选择“创建完整备份”，将生成的 ZIP 复制到其他磁盘或电脑。在目标软件中选择“从备份恢复”，会替换当前题目、体系、学习数据、设置、附件及导出，并自动先备份当前内容。成功后会显示恢复前备份的位置。

备份会校验清单、文件大小、校验值和主要数据字段，恢复时重定位附件。图片识别原文、校对草稿和应用状态也随题目备份。缺失附件会阻止完整备份；当前数据无法备份时也会中止恢复。备份不包含运行环境、识别模型、日志或旧备份，只接受本软件生成的 ZIP。解压后总量上限为 4GB，数据 JSON 单文件上限为 64MB；请保留足够临时空间。直接复制旧工作区不保证附件路径自动更新，迁移请使用备份入口。

恢复失败时会尝试回滚；若磁盘故障导致回滚也失败，错误信息会给出恢复前备份及原数据暂存位置，请保留现场。此功能不能替代异地备份，也不保证断电后自动恢复。

## 2. 四步走完整流程

```
导入错题  →  选/建分类体系  →  一键分类  →  导出归档
   ①              ②                ③           ④
```

左侧导航栏的五个入口就是按这个顺序排的。第四个「反馈与增量优化」不是必经步骤，是让你看系统学到了什么。

**想先看效果**：去「导入与预览」页点右侧的 **载入示例错题**，会载入 155 条内置演示与评测数据，然后直接点「一键分类」。

**忘了怎么用**：点左下角的 **?** 按钮，新手引导随时可以重看。旁边的月亮/太阳按钮切换深浅色主题。

## 3. 导入与预览

### 三种导入方式

**单条录入**
点右侧「单条录入」，在中间的文本框里敲题干。公式用 `$...$` 包起来，例如：

```
求极限 $\lim_{x \to 0}\frac{\tan x - \sin x}{x^3}$，用等价无穷小替换。
```

> 只要你会用 `$...$` 写公式，就完全不需要装任何识别引擎。

**批量导入 TXT / Excel**

TXT 有两种写法，系统自动判断：

```
一条错题占一段，段与段之间空一行。
题干可以有多行，选项也可以写进来。

第二条错题从这里开始。
```

或者一行一条。`#` 开头的行会被当注释忽略。

> Windows 记事本默认存的是 GBK 编码，系统会自动识别，不用你操心。

Excel 更省事，表头随便写，系统会自己认：

| 题干 | 学科 | 题型 | 标注 |
|---|---|---|---|
| 求极限… | 高等数学 | 公式类 | 等价无穷小用错了 |

「题干」这列叫「题目」「错题」「内容」`question` 都认；「题型」列写「公式类」「公式」`formula` 也都认。认不出来时默认用第一列当题干。

表格支持 XLSX、CSV 和 TSV，旧版 XLS 请另存为 XLSX。CSV/TSV 会尝试常见中文编码。附件列可以使用相对于表格目录的路径，例如 `图片/题目.png`；导入时复制到工作区，不再依赖原始文件的位置。

默认跳过题干、标注、学科、题型、优先级和附件内容完全相同的题目，取消列表上方的勾选可保留重复项。部分文件或表格附件行出错时，其余成功项仍会保存；展开错误详情，修正源文件后点击“重试失败的导入”。部分行失败的表格会重新读取，保持去重勾选可避免重复加入已成功的行。

导入和分类期间，页面编辑与其他数据任务暂时锁定。顶部“停止任务”会在当前文件或当前题处理完后停止；正在执行的识别步骤不能立即打断。期间点击关闭会请求停止，任务结束后请再次关闭窗口。

**导入图片 / 音频**

- 印刷题目截图 → 使用“图片文字：识别与校对”提取文字、人工校对，再应用为题干。
- 复杂公式图片 → 导入后可点“公式图片：识别与校对”；需要本地 pix2tex 模型，确认 LaTeX 后才参与分类，复杂结构仍需人工核对。
- 听力音频 → 导入后可点“听力音频：转写与校对”；需要本地 faster-whisper 或 openai-whisper 模型，确认转写后才参与英文特征提取。

也可以「导入整个文件夹」，一次把目录下所有图片和音频扫进来。

公式和听力模型的默认目录是工作区 `models/formula` 与 `models/audio`，也可以用 `MC_MODEL_DIR` 指定根目录。项目提供 `python tools/check_media_models.py` 做只读检查；它不会安装或下载模型。听力当前验证组件为 `faster-whisper==1.2.1`，模型使用 `base`、CPU `int8`；准备模型时可运行一次本地模型准备脚本，运行期不会自动下载。模型文件和组件准备完成后再点击对应识别按钮，缺模型时程序会保留原题并给出失败原因。

首次使用印刷文字识别，双击项目内“安装图片识别.bat”；本机已安装。此功能当前要求 Python 3.11 或以上，建议 3.12 或 3.13。运行环境和三个本地模型保存在项目 `.venv`，模型约 30.3 MiB。安装完成后的识别不联网、不上传图片；缺失或损坏的模型会明确报错，需重新运行安装脚本联网修复，不能靠识别重试自动下载。

### 图片识别与校对

1. 导入图片后在列表选中题目，点击右侧“图片文字：识别与校对”。一张图建议只包含一道题，先选好学科。
2. 点击“开始识别 / 重试”。识别在独立进程后台运行，等待完成后对照左侧原图修改右侧“校对文本”。原图默认适应宽度，也可切换固定比例并滚动查看。
3. “原始识别与逐行分数”保留识别原文，编辑不会覆盖它。模型分数不等于准确率，所有文字都需要核对。
4. 点击“保存校对草稿”只存草稿；点击“应用为题干”才更新题干并作废旧分类。有旧题干时会先确认是否替换。
5. 关闭窗口，去分类页执行分类。导出 Excel 使用已应用的题干，附带图片识别状态；草稿未应用时不会混入分类或题干导出。

可以保存草稿后关闭，下次继续编辑；修改过已应用的草稿或另行修改题干时，会显示待重新应用状态。重新识别需确认替换草稿，已有题干保持原样。保存失败时编辑内容留在窗口中，可以重试；关闭前请确认是否保存。

识别期间可“取消本次识别”：当前进程结束后丢弃结果，原有内容不变。运行中不允许关闭校对窗口或启动分类、备份等其他任务。单张超过 30 MiB、2500 万像素或没有可识别文字时会提示处理方法。复杂公式、手写、图形含义仍需人工补充。

### 预览与补充标注

列表上方可以搜索题干、标注或附件文件名，不区分英文大小写，与学科和题型筛选同时生效。输入内容按完整的原文字片段匹配，不做语义搜索，也不直接搜索图片和音频内容。点击搜索框旁的“清空”，仅清除搜索文字，保留其他筛选条件。

编辑后列表会重新匹配。如果当前题目不再符合条件，右侧仍可继续编辑，列表标题会显示当前匹配数量。点击“单条录入”会清空搜索，并沿用当前筛选的学科和题型，避免新题被搜索条件隐藏。

选中左侧列表里的一条错题，右边会显示：

- **学科 / 题型**：系统自动判断的，判错了直接改
- **题干文本**：可以直接编辑
- **图片 / 音频预览**：图片直接显示，音频可以播放
- **标注补充区** ← **这块最值得花时间**

标注会和题干一起参与分类。对图形题和听力题尤其重要——图里画了什么，系统认不出来的部分全靠你这一句话。系统会按题型给你提示该写什么：

- 图形题：图中元件、标注参数、考查知识点
- 听力题：场景、关键信息、题型

写标注时顺手记一句错因（"漏画了正压力分量"），系统还能顺便帮你把「错误类型」也分对。

## 4. 搭建你自己的分类体系

系统内置了高数、大物、大英、线代、概率五门课的默认体系，直接能用。但**按你自己老师的讲义章节重新分，效果会好得多**。

### 界面分三栏

```
┌── 体系树 ──┬──── 标签编辑 ────┬── 标准错题样本 ──┐
│ 高等数学    │ 标签名称          │ 样本1            │
│  知识点(10) │ ─────────────    │ 样本2            │
│   函数与极限│ 关键词库          │                  │
│   导数与微分│  定积分           │ [添加][更新][删除]│
│   定积分 ←  │  牛顿莱布尼茨公式  │                  │
│  错误类型(8)│  变限积分         │ [批量导入样本]   │
│  题目难度(3)│ ─────────────    │                  │
│  复习优先级 │ 特征权重覆盖      │                  │
└────────────┴──────────────────┴──────────────────┘
```

### 怎么建

1. 右侧点 **新建分类体系** → 填名字（比如「高等数学（张老师班）」）、选学科
2. 在体系树里选中「知识点」维度 → 右侧点 **新建分类标签** → 填章节名
3. 选中新标签，在中间填 **关键词库**，一行一个

**关键词怎么填才好用**：填这个知识点的**专有名词**，覆盖同一个概念的不同说法。

```
定积分
牛顿莱布尼茨公式
变限积分
反常积分
旋转体体积
弧长
```

3~5 个是底线，多多益善。填得太少的话，界面下方会提醒你。

> 关键词是**第一层粗筛**的依据。一个标签一个关键词都没有，它在粗筛阶段永远不会被选中，后面再准也轮不到它。

4. 右侧贴几条 **标准错题样本**——直接把典型题的题干粘进去。样本越贴近你自己的题目，分类越准。也可以「批量导入样本」，把一批已经归好类的题一次性导进来。

修改自动保存，新分类任务会使用更新后的体系。分类页优先为同学科题目使用当前选中的体系；混合学科中其他课程的题目使用其对应体系。

### 特征权重（进阶，可以不管）

系统默认已经按「学科 × 题型」配好了权重（高数公式题更看重公式特征，英语听力题更看重题型特征）。只有当你确信某个标签需要特殊对待时，才勾选「为该标签单独指定各特征通道的权重」。

### 分享给同学

右侧「导出体系」会导出一个 JSON 文件，发给同学，对方「导入他人的体系」就能用。一个班一起把词库养肥，比一个人闷头填快得多。

## 5. 一键分类与修正

### 分类

顶部选好分类体系 → 点 **一键分类**。系统会自动：

1. 多模态预处理（认公式、认图、转音频、分词）
2. 第一层：关键词粗筛，从所有标签里挑出 3~5 个候选
3. 第二层：多特征融合精匹配，从候选里选出最终答案

155 条题大约几秒钟跑完。分类过程在后台跑，界面不会卡。

右侧还有：

- **重新分类全部**：忽略已有结果重跑（你已经人工改过的维度会被保留，不会被覆盖）
- **只分类选中项**

### 看懂分类依据

中间「分类结果与依据」区把整个判断过程摊开了：

```
知识点：定积分及其应用            0.612    
    定积分及其应用               0.612   粗筛命中：定积分、牛顿莱布尼茨公式
        特征通道                        文本 0.58×65%  公式 0.71×15%  题型 0.12×10%  学科 0.30×10%
    不定积分                     0.284   粗筛命中：积分
    无穷级数                     0.061   召回兜底
```

- **粗筛命中**：这条题的哪些词命中了这个标签的关键词
- **召回兜底**：一个关键词都没命中，是为了保证不漏才补进来的候选
- **特征通道**：四个通道各自的相似度 × 权重

下方还会列出提取到的特征词、识别出的 LaTeX、听力转写结果和耗时。

**置信度偏低会标红**，左侧筛选框里选「置信度偏低（建议复核）」可以把它们挑出来集中处理。

### 改错

右侧「修正操作」区，每个维度一个下拉框，选对的那个就行。改完系统会立刻：

- 把这条题的判别特征增量并入正确的分类
- 把误判分类里重合的词调弱一点
- 微调这个「学科 × 题型」的特征权重
- 把学到的新词补进粗筛索引

整个过程**不重新训练、不联网**，瞬间完成。

> 一两次修正的效果有限，反馈也可能影响其他题目的分类。当前题目的人工结果会保留；对后续题目的效果仍需复核。详见 README 的「已知局限」。

**采纳为标准样本**：如果这条题很典型，点右侧这个按钮，它会被固化进分类体系，比反馈增量更持久、也能跟着体系一起导出分享。

**一键标记复习优先级**：选中若干条 → 点「高/中/低」。

## 6. 反馈与增量优化

这一页不用来干活，用来**看系统到底从你的修正里学到了什么**——它不是个黑盒。

- **人工反馈日志**：每一次修正的时间、原判、改成了什么、把哪个通道的权重推向了哪边
- **差异化特征权重规则**：每个「学科 × 题型」桶的权重条形图，被你的反馈改写过的会加粗排在前面
- **人工修正率趋势**：曲线往下走说明系统越判越准

> 趋势曲线是**代理指标**：统计的是"被你改过的比例"，不是严格意义上的准确率（你不一定会去改每一条错判）。

右侧可以「导出反馈日志」成 Excel（能直接放进结题报告），也可以「重置权重规则」或「清空全部学习成果」回到出厂状态——**学到的东西看得见，也删得掉**。

## 7. 导出与归档

### Excel 分 sheet 归档

选好「按哪个维度分 sheet」（知识点 / 错误类型 / 难度 / 复习优先级 / 你自定义的任意维度），右侧点 **一键导出 Excel**。导出的表包含：

- **全部错题**：总表，含所有维度的分类结果与置信度
- **分类统计**：每个标签有几条题、占比多少
- **知识点-定积分及其应用**、**知识点-无穷级数**……：每个标签一个独立 sheet

列宽已经调好并冻结表头，适合打印整理；正式打印前请核对长题干、分页和附件索引。

### 媒体归档

点 **导出媒体归档**，图片和音频会按分类标签分文件夹复制出来：

```
错题媒体归档_20260717_143022/
├── 知识点/
│   ├── 光的干涉与衍射/
│   │   ├── 双缝干涉.png
│   │   └── 光栅.png
│   └── 电磁感应/
│       └── 导轨.png
└── index.csv          ← 索引，Excel 双击就能打开，中文不乱码
```

### 导出前先看预览

右侧「导出结构预览」会先告诉你会生成哪些 sheet、每个几条题，还会提醒"有 N 条还没分类"之类的问题，免得导完才发现不对。

## 8. 常见问题

**Q：一定要装那三个识别引擎吗？**
不用。普通印刷图片只需“安装图片识别.bat”提供的 RapidOCR 与 ONNX Runtime；公式图片和听力转写需另外准备对应本地模型。未安装时仍可手动填写题干、内联公式和标注参与分类，识别结果必须人工确认。

右上角“环境自检”会区分组件未安装、模型未准备、未验证、正在加载、已加载、初始化失败和状态检查失败，并显示处理提示。印刷文字识别成功后显示“本地文字识别已验证”，任务结束会释放模型。点击“刷新状态”不会加载模型或语料，也不会安装组件或触发模型下载。检测到组件、模型文件或曾识别成功，都不代表所有图片识别效果已经验收。

**Q：分类不准怎么办？**
按这个顺序试：
1. 去「分类体系管理」给这个标签**多加几个关键词**（最有效）
2. 贴几条**标准样本**
3. 在分类页把这条题**改对**，让系统学
4. 检查题干的**标注**写得够不够——图形题和听力题特别依赖这个

**Q：我改了关键词，要重启吗？**
不用。改完立刻生效。

**Q：程序崩了 / 报错了怎么办？**
数据是原子写入的，不会丢。看 `~/.mistake_classifier/logs/app.log`。实在不行 `python main.py --reset` 清空工作区重来（会删掉所有错题，慎用）。

**Q：Excel 导出失败？**
先确认那个 Excel 文件没在别的程序里开着。标签名里带 `/ \ * ? : [ ]` 这些字符是没问题的，系统会自动处理。

**Q：听力音频播放不了？**
点「用系统播放器打开」。部分精简版系统缺音频后端，程序内嵌的播放器用不了，但不影响转写和分类。

**Q：能多人一起用吗？**
不能，单机单用户。但可以互相「导出体系 / 导入体系」来共享词库。
