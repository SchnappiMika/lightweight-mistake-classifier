## 二、已经执行的验证

1. 本机独立测试环境中，完整自动化测试为 **209 项通过、1 条警告，耗时约 31.75 秒**。警告来自既有 pytest 夹具写法，不是本次测试失败。
2. 新增流程测试覆盖编辑顺序、旧结果失效、当前体系选择、标签同步、学习重置、空题统计和批处理失败清理；还覆盖“编辑题目 → 自建体系分类 → 人工修正 → 重新读取已保存数据 → Excel 导出”。
3. 使用实际新运行环境执行 `启动软件.bat --check`，退出码为 0，Qt 界面环境初始化检查通过。
4. 使用实际 `main()` 入口，在独立临时工作区启动主窗口，再自动关闭，结果为 `STARTUP_SMOKE_EXIT=0`。此项采用 Qt offscreen 模式，不替代真实屏幕操作验收。

测试通过说明上述已覆盖行为可复现，不代表多模态识别、全部用户操作或校创验收已经完成。未重新测定分类准确率，也未以这些修复宣称算法效果提高。

## 四、后续按什么顺序做

### 第二批：数据保存、导入与迁移

- 做完整备份与恢复入口，覆盖题目、体系、学习数据、设置和附件；恢复前验证备份并保存原数据。
- 统一附件导入到工作区，解决 Excel/CSV 相对路径及跨电脑路径失效。
- 补齐批量导入部分失败提示、重试和重复导入处理。
- 完善任务状态与互斥，避免分类过程中修改共享数据造成结果混乱。
- 验收：用带附件和自建体系的数据备份，迁到一个新工作区后，题目、附件、修正和学习结果都能恢复。

### 第三批：图片、公式和听力真正可用

- 完成识别组件与模型准备流程，展示实际可用状态、本地模型位置与初始化错误。
- 为真实图片 OCR、公式识别、音频转写补齐后台运行、进度、失败重试及结果校对入口。
- 单独验证断网运行与首次安装，记录真实媒体处理耗时。
- 验收：分别用真实图片、公式截图和音频完成“导入 → 识别 → 人工校对 → 分类 → 保存和导出”，不能用手填文本代替识别成功。

### 第四批：复习使用与可交付版本

- 完善查找、低置信度复核、答案和解析等内容字段，以及适合打印的错题本导出。
- 处理混合体系导出，制作并验证 Windows 发布包。
- 请普通同学独立操作，记录发现的问题和修复结果。
- 验收：在未配置开发环境的 Windows 电脑上完成安装或解压启动，以及一整套日常使用流程。

### 第五批：结题证据和软著材料

- 以申报书为依据整理“承诺功能—实现位置—验收结果—证明材料”的对照表。
- 用独立真实题目评测，记录分类准确率、识别效果、耗时及反馈可能导致的退步。
- 按最终版本重写操作手册与测试报告，使用真实界面截图。
- 确认团队、学校与指导教师相关的权利归属，并核对第三方依赖许可。
- 确定一致的软件名称、版本号和权利人，再准备与成品一致的程序及文档鉴别材料；办理时以官方当期要求为准。

这些步骤是后续开发与验收安排，不是已完成事项。当前可以先验收核心文本操作，尚不能宣称申报书的全部多模态能力已经实现，也不能据此保证软著登记结果。
