# 轻量化错题自动分类管理系统

**Lightweight Mistake Classifier** —— 基于传统文本分类方法的大学生轻量化错题自动分类管理系统

一个**完全离线、不需要编程环境、不需要模型训练**的 Windows 桌面错题分类工具。用经典的关键词匹配与 TF-IDF 余弦相似度，把"抄错题、按知识点分类"这件事从几十分钟压缩到几秒钟；分类体系由使用者自己定义，改完立刻生效。

## 为什么做这个

大学生整理错题有四类现实痛点：

1. **手动整理效率极低** —— 抄录、按知识点归档占用大量课余时间，还容易分错。
2. **现有工具付费门槛高** —— 自动分类、批量导出、OCR 大多要开会员。
3. **分类适配性差** —— 平台统一的知识点体系，适配不了各校各老师的教学进度。
4. **功能冗余不轻量** —— 题库、网课、刷题一应俱全，而学生只想快速分个类。

这个项目针对这四点：分类体系自己建、全流程本地跑、不花一分钱、双击就能用。

## 主要特性

| 能力 | 说明 |
|---|---|
| **多格式导入** | 手动录入、TXT / XLSX / CSV / TSV 批量导入、图片、音频；附件统一归档、自动去重、部分失败保留并支持重试 |
| **零代码自建体系** | 维度、标签、关键词、标准错题样本、标签特征权重全部可视化编辑，保存即生效，不用改代码、不用重启 |
| **双层分级分类** | 关键词粗筛保留 3–5 个候选，再做多特征融合的 TF-IDF 余弦精匹配 |
| **多模态识别与校对** | 图片文字（RapidOCR）、公式（pix2tex）、英语听力（faster-whisper）本地离线识别；**原始结果 / 用户草稿 / 确认内容三层分离**，只有确认过的内容才参与分类 |
| **人工修正与增量反馈** | 改错了当场修正，系统增量更新对应标签的特征与权重，不做全量重训 |
| **按体系隔离导出** | 按自定义维度分 sheet 归档，媒体类错题按标签分文件夹；同学科两套体系不会混到一起 |
| **完整备份恢复** | 一个 ZIP 打包题库、体系、反馈学习、设置、附件与历史导出 |
| **全流程离线** | 识别进程在启动时就把 socket 连接替换为抛异常，机制上禁止联网 |

内置 5 套学科分类体系（高等数学 10 个知识点、大学物理 14 个、大学英语 9 个、线性代数 5 个、概率论与数理统计 6 个），另附 1 套通用体系。

## 快速开始

### 方式一：直接用打包好的 Windows 版

从交付包中解压 `错题自动分类-Windows版.zip`，**保留整个目录**，双击 `错题自动分类.exe`。不需要安装 Python 或任何依赖。

> 首次使用图片、公式、听力识别时需要在本机加载模型，第一次会明显偏慢（公式识别冷态可能接近两分钟），之后恢复正常。

### 方式二：从源码运行

```powershell
# 1. 创建虚拟环境并安装依赖
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock-windows.txt

# 2. 启动
.\.venv\Scripts\python.exe main.py
```

也可以直接双击 `启动软件.bat`，它会自动检查并准备运行环境。

### 运行测试

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
```

### 打包 Windows 发布版

PyInstaller 在中文路径下会解析不到 Qt 插件目录，需要先用 `subst` 映射一个 ASCII 盘符：

```powershell
subst S: "<项目绝对路径>"
cd /d S:\
S:\.venv\Scripts\python.exe tools\build.py --onedir
S:\.venv\Scripts\python.exe tools\stage_release.py S:\dist\错题自动分类 `
    --model-dir "<模型根目录>" --formula-python S:\.venv-formula\Scripts\python.exe
subst S: /D
```

## 技术方案

### 双层分级分类

```
错题 ──预处理──▶ 多模态特征
                    │
                    ├─ 第一层 关键词粗筛 ──▶ 3–5 个候选标签
                    └─ 第二层 融合精匹配 ──▶ TF-IDF 余弦 + 差异化权重 ──▶ 最高分标签
```

粗筛有三重兜底，保证未登录词也能命中：分词精确命中、`cut_for_search` 子词扩展、原文子串扫描（覆盖 3 字以上关键词）。精匹配融合文本、公式、题型、学科四类特征并差异化加权，不依赖任何深度学习模型。

### 公式—知识点映射

LaTeX 无法直接分词（`\int_{0}^{1} x\,\mathrm{d}x` 会被切成 `int`、`0`、`1`、`x`……）。项目用 85 条正则规则把公式的**结构特征**映射成知识点特征词：带上下限的 `\int` 映射"定积分"，裸 `\int` 映射"不定积分"——用符号结构区分纯文本无法区分的知识点。

### 为什么不用大模型

- **部署**：目标用户在普通笔记本上双击运行，不能要求装 CUDA、下载几 GB 权重。
- **成本与隐私**：云端接口意味着费用、联网与题库外泄风险，而错题是学生自己的数据。
- **可解释**：每个分类结果都能看到命中的关键词与得分，用户可以判断该不该信。

## 评测结果

| 指标 | 申报目标 | 实测 |
|---|---|---|
| 纯文本错题分类准确率 | ≥95% | **98.8%**（85/86） |
| 全类型平均分类准确率 | ≥90% | **98.1%**（152/155） |
| 公式 / 纯文本 / 图形核心特征提取 | ≥90% / ≥95% / ≥90% | 100% / 100% / 100% |
| 英语核心特征提取 | ≥90% | 93.3% |
| 分词错误率 | ≤3% | 0%（0/121） |
| 单条文本分类耗时 | ≤1 秒 | 平均 **25.1 ms** |
| 自动化回归 | — | **826 项通过** |

评测集为 155 条人工标注错题，覆盖 5 个学科、44 个知识点标签、5 种题型（纯文本 86 / 公式 37 / 英语阅读完形 21 / 图形 8 / 英语听力 3）。

**口径说明**：该评测集与词典、规则在建设过程中相互参考，属同源闭卷自测，可确认功能正确与回归趋势，**不能等同于对未见真实题目的泛化承诺**。项目另采集了与规则调试隔离的公开语料做迁移测试（OpenStax 190 题、SQuAD 30 题），结果与局限写在 [功能测试报告](docs/功能测试报告.md) 第三、四章。

## 已知限制

- **多模态耗时**：图片识别约 2 秒、31.88 秒音频转写约 2 秒、公式识别约 7 秒（冷态首次接近 2 分钟），均超过"每题 1 秒"的目标。瓶颈在模型推理与进程启动，不在分类算法。
- **公式混排**：整页多公式混排的图片识别不可靠，需裁剪到单个公式再识别；裁剪、反色、缩放功能已提供。
- **图形题**：OCR 只提取图内文字，不具备图形语义理解；未命中知识点时需要人工补关键词或手动选。
- **反馈提升**：增量反馈机制可用，但"修正后同类型准确率稳定提升"未获稳定证据，部分分组出现过退步。

以上均如实记录在 [结题报告](docs/结题报告.md) 与 [结题验收对照矩阵](docs/结题验收对照矩阵.md) 中，未作选择性呈现。
