# 错题自动分类管理系统

基于传统文本分类方法的大学生轻量化错题自动分类管理系统

## 项目简介

本项目面向大学生全学科错题整理的场景痛点，打造一套**轻量化、可离线、高适配**的错题自动分类管理系统。
系统采用经典 TF-IDF 权重计算与余弦文本相似度匹配作为纯文本兜底方案，
创新地引入多模态预处理（公式 OCR、图形 OCR、音频转写）与"关键词粗筛-多特征融合精匹配"双层分级分类策略，
在不依赖大模型与云端算力的前提下，实现多类型错题的精准自动分类。

## 功能模块

| 模块 | 功能 |
|------|------|
| 多模态错题导入与预览 | 单条手动录入、TXT/Excel 批量导入、图片/音频本地导入 |
| 零代码分类体系管理 | 可视化创建/编辑分类标签、关键词库、特征权重 |
| 多特征融合一键分类 | 关键词粗筛 → 多特征融合精匹配，一键全流程处理 |
| 分类结果修正与反馈优化 | 手动修正后自动增量更新特征库，准确率持续提升 |
| 个性化结果导出 | 按分类维度分 sheet 导出 Excel，图片/音频分文件夹归档 |

## 技术栈

- **语言**：Python 3.13
- **文本处理**：jieba、NLTK、scikit-learn（TF-IDF + 余弦相似度）
- **公式识别**：pix2tex（LaTeX-OCR）
- **图文识别**：PaddleOCR
- **音频转写**：Whisper
- **GUI 界面**：PyQt5
- **数据读写**：pandas、openpyxl
- **打包部署**：PyInstaller

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 运行程序
python src/main.py
```
