# 真实验收素材采集模板

当前项目暂没有用户提供的真实题目、公式截图、听力音频或校内试用记录。本文件是采集和记录格式，不是已经完成的验收结论。当前目录另有 Wikimedia Commons 公开候选素材，但它们不能替代校内真实数据。可用 `python -m tools.make_acceptance_template samples/acceptance_records.csv --rows 30` 生成 CSV 空表。

当前已增加 `samples/public_acceptance/` 作为公开候选素材集。其 `manifest.json` 保留 Wikimedia Commons 来源页、许可证、下载状态和 SHA-256；`gold_knowledge` 与 `gold_core_features` 为空，必须由人工复核后才能作为封存测试集。

当前公开候选集已完成一次工具链运行：4 张图片经过 RapidOCR 文字提取，1 个 WAV 音频使用本机 `faster-whisper==1.2.1` 的 `base` 模型完成转写。图片文字不等于公式 LaTeX 或图形关系理解，音频转写也不等于知识点分类正确；所有机器结果仍需人工核对，不能直接填入 `gold_*` 字段或作为申报书准确率。

公式图片识别仍未准备 pix2tex。若后续要验收公式结构，须在得到明确授权后准备本地模型，并单独记录模型版本、离线状态、原图、人工 LaTeX 参考答案和识别耗时。

## 每条素材

- `sample_id`：唯一编号；截图、裁剪版和转写文本不能重复计数。
- `source_description`、`permission_scope`：来源和允许使用范围，公开前去除个人信息。
- `subject`、`qtype`：高等数学、大学物理、大学英语及公式、图形、阅读、完形、听力等。
- `input_path`：原始文件路径；不要只保存手工输入的题干。
- `gold_knowledge`、`gold_core_features`：由独立标注者在运行规则冻结前标注。
- `gold_error_cause`、`gold_difficulty`：只有题目或学生记录明确支持时填写，否则使用“未确定”。
- `expected_transcript_or_latex`：听力转写或公式 LaTeX 的人工参考答案。

## 自动流程记录

填写原始识别/转写、确认后的文本、预测标签、成功或失败原因、输入时长、识别、分类、保存导出和总自动耗时。用户校对时间单独记录，不能从总自动耗时中悄悄删除识别阶段。申报书要求的每题不超过 1 秒应按完整流程实测；当前公开音频一次转写约 3 秒，尚未满足该指标，不能把结果写成达标。

识别失败、损坏文件、取消、超长音频、模型缺失和权限错误均应保留记录。只保留识别成功样本会高估全流程结果。

## 数据集隔离

调试集可修改规则；反馈学习集只用于增量实验；封存测试集在最终规则和模型版本冻结后只运行一次。相同题目的改写、截图、人工转写不能跨集合当作独立样本。

## 试用记录

每位试用者记录系统版本、操作系统、硬件、启动、导入、识别或标注、分类、人工修正、关闭重开和导出过程中的问题、修复版本和复测结果。开发者自动化测试不能替代真实学生试用。
