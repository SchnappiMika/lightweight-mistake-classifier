## 真实数据与量化边界

155 条内置评测集与 87 条特征集、以及词典和规则在建设过程中相互参考，属**同源闭卷自测**，历史与当前的 98.1%/98.8% 不能外推到独立 gold 题库。申报书原文规定的验收口径正是"基于 150 余条人工标注样本"，本项即按该口径报告，同时必须标注该局限。

独立语料（OpenStax 190 题 / SQuAD 30 题）与规则调试隔离，保留来源、许可与哈希。迁移结果为英语 26/30、科学 91/190（弃权 31）；科学偏低主因是英文语料与中文关键词库的**跨语言错配**，不作为达标依据，只作稳健性披露。人工逐题确认流程已实现（`tools/review_acceptance.py`），尚未执行。

反馈实验在预注册种子 17/42/2026 下：科学组 0 / −13.6 / −2.5 pp，英语组 0 / +13.3 / +13.3 pp。机制可用，但"提升 ≥5%"未获稳定证据。

## 结题尚缺

1. **多模态全流程未达每题 1 秒**：图片 1.95–2.44 s、音频 2.08–2.75 s、公式 6.77–8.12 s（冷态可达 143 s）。瓶颈在模型推理与进程启动，不在分类算法。
2. **反馈提升 ≥5% 未证实**，科学组存在退步。
3. **独立人工 gold 未完成**：190+30 题的标签目前是章节/任务映射，需人工逐题确认。
4. **设备验证未开展**：干净无 Python Windows、macOS、i5-8250U/8GB 低配。校内同学真实试用已完成，记录见 [真实试用与迭代记录](真实试用与迭代记录.md)。
5. **源码未公开发布**：目录无版本库、无远程仓库；发布前需处理 PyQt5 GPL v3 合规、补齐 9 个组件许可全文、清理含用户名的本机路径、统一软件名写法。详见 [开源交付与许可说明](开源交付与许可说明.md)。

执行方法见 [试用与外部验证方案](试用与外部验证方案.md)；逐条判定见 [结题验收对照矩阵](结题验收对照矩阵.md)；结论性材料见 [结题报告](结题报告.md)。
