# Windows 发布与组件说明

更新日期：2026-10-29，版本：1.0.0。

## 打开目录版

完整目录为 `dist/错题自动分类/`，双击 `错题自动分类.exe`。请整体复制或解压，保留 `media_worker.exe`、`_internal` 和 `models` 等内容。程序目标为无需另装 Python 使用；当前本机 Windows 11 冒烟成功，无 Python 的干净电脑仍需验收。

数据默认保存在用户目录 `.mistake_classifier`。迁移题库用“备份与恢复”；模型及运行组件随完整发布目录携带。公式独立Python3.12运行时位于 `formula_runtime/python/python.exe`，由媒体进程自动调用，默认读取随包模型，无需用户另装Python或设置MC_MODEL_DIR。

## 组件状态

| 组件 | 当前状态 |
|---|---|
| 桌面与分类 | PyQt5、jieba、分类与表格依赖随目录构建 |
| 图片文字 | RapidOCR 模型、ONNX Runtime；发布包已用文件得到 OCR 输出，复杂数学结构需公式组件 |
| 听力 | faster-whisper 1.2.1、CPU int8、Whisper `base` 约 145MB 随包；公开 WAV 本机及打包进程转写成功 |
| 公式 | pix2tex0.1.4/Python3.12/torch2.5.1 CPU裁剪公式一图一致，混排整图一图不可靠；随包迁移已通过真实exe验证 |

GUI 与识别进程使用两个独立 PyInstaller Analysis，媒体任务交给 `media_worker.exe`，通过文件传递请求与结果。构建曾发现 Qt 自带旧 `MSVCP140.dll` 导致识别进程退出，已统一运行库后复测。不要单独复制 DLL，或用旧构建目录覆盖新目录。

首次组件准备需要联网；运行时应读取本地模型。缺模型、格式不支持和识别失败会显示原因，已有题目及上次确认内容保留。开发者可用 `tools/check_media_models.py` 检查模型，或用 `MC_MODEL_DIR` 指定模型根目录。

## 识别与校对

导入附件，选对题型，打开相应“识别与校对”或“转写与校对”。对照原图或原音核对原结果与草稿，再明确确认；回分类页重新分类。仅保存草稿不应用新内容。重点检查上下标、正负号、单位和英语否定词。

`发布包冒烟记录.json` 是本机隔离冒烟证据。真实分类准确率、媒体每题 1 秒、干净设备及真实学生试用需要独立验收，不能由冒烟成功推定。

最终本机包完整冒烟约65.40秒，覆盖图片、音频、公式、自动确认分类、Excel、备份和重载；这是整个测试脚本耗时，不是单题速度。自动确认仅验证数据链路，不是人工复核，详见 `发布包冒烟记录.json`。
